# Quicklink Landing

Адаптивный лендинг сервиса Quicklink, выполненный на HTML и CSS.

## Реализовано

- Адаптивная вёрстка для desktop и mobile.
- Мобильное меню.
- Вёрстка нескольких секций лендинга.
- Работа с Flexbox и Grid.
- Адаптация интерфейса под разные размеры экрана.

## Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
